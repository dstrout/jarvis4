# Topic Deep Dive

When a question requires more than a single search to answer well, this recipe
structures a multi-angle research approach.

## Steps

1. **Initial search**: Search for the topic directly to get an overview.
2. **Identify gaps**: From the initial results, identify what questions remain unanswered or what claims need verification.
3. **Targeted follow-ups**: Run 2-3 additional searches with refined queries targeting the gaps. Try different angles:
   - Technical/detailed query
   - Recent news or developments query
   - Contrarian or alternative perspective query
4. **Cross-reference**: Compare findings across sources. Note where sources agree and disagree.
5. **Synthesize**: Combine into a comprehensive answer that acknowledges uncertainty where it exists.

## Tips

- Don't just repeat the same search with different words. Each follow-up should seek genuinely new information.
- If sources conflict, say so — don't silently pick one.
- Cite specifics: names, dates, numbers. Vague summaries are less useful than concrete facts.
- Cap at 4 total searches to keep response time reasonable.
