# Skills

A skill is a Markdown file (`SKILL.md`) with YAML frontmatter describing a
capability: what it does, what it needs, and step-by-step instructions for
using it. Agents load skills on demand via `core/skill_loader.py` rather than
carrying every instruction in their system prompt, which keeps prompts small
while making a large surface of capability reachable.

## Provenance and licensing

This directory mixes two sources. Both are committed so that a fresh clone is
immediately usable, rather than requiring a separate generation step.

### Vendored: 92 generated skills (Apache-2.0)

The `gws-*`, `recipe-*` and `persona-*` skills, except the three listed below,
are a vendored snapshot generated by the **Google Workspace CLI**:

- Package: [`@googleworkspace/cli`](https://github.com/googleworkspace/cli) v0.11.1
- License: Apache-2.0 — full text in [`LICENSE`](LICENSE)
- Generated with: `gws generate-skills`

They are **not** authored by this project. They are included verbatim so the
repository installs and runs without an extra generation step, and so the exact
version this project was developed against is pinned. `docs/skills.md` is the
generated index of these 92.

To regenerate them yourself instead of using the snapshot:

```bash
npm install -g @googleworkspace/cli
cd skills && gws generate-skills
```

Note that the Google Workspace CLI is not an officially supported Google
product, and these skills require the `gws` binary on `PATH` plus an
authenticated Google account.

The `metadata.openclaw` key in each file's frontmatter is the metadata schema
namespace the generator emits — it is a format identifier, not an authorship
claim.

### Project skills (MIT)

Three skills are original to this project and covered by the repository's
[MIT license](../LICENSE):

| Skill | Purpose |
|-------|---------|
| `recipe-morning-briefing` | News headlines, local weather, and the day ahead |
| `recipe-sport-update` | Standings, recent results and next event for a league |
| `recipe-topic-deep-dive` | Multi-angle research when one search is not enough |

Unlike the vendored skills, these drive Jarvis4's own tools (`web_search`,
`get_weather`, `get_forecast`) rather than the `gws` CLI, so they work without
any Google Workspace setup.

## Writing your own

Create a directory with a `SKILL.md`:

```markdown
---
name: recipe-my-skill
version: 1.0.0
description: "One line describing when this skill applies."
metadata:
  openclaw:
    category: "recipe"
    requires:
      tools: ["web_search"]
---

# My Skill

## Steps

1. ...
```

`skill_loader` discovers it at startup. The `description` is what an agent sees
when deciding whether the skill is relevant, so write it as a trigger condition
rather than a title.
